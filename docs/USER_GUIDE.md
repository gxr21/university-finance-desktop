# دليل المستخدم

## تسجيل الدخول

من `/login` أدخل اسم المستخدم أو رقم الهاتف أو البريد مع كلمة المرور. الرسالة عند الفشل موحّدة ولا تكشف وجود الحساب.

الحساب الجديد من `/register` ينتظر موافقة الإدارة ولا يمنح صلاحيات مالية.

## أمين الصندوق

1. ابحث عن الطالب.  
2. راجع القسط والخصم والمتبقي كما يحسبه الخادم.  
3. أدخل المبلغ المستلم.  
4. أكّد العملية. يصدر وصل فريد ويُؤرشف حتى لو أُلغيت الطباعة.  
5. اطبع A5 ثم سجّل تأكيد خروج الورقة عند الحاجة.

لا يمكن حذف دفعة. التصحيح يتم بعكس موثّق من مدير الحسابات.

## محاسب المصروفات

أنشئ كتاباً ببنود غير محدودة، اختر خزنة المصدر، وقدّم للمراجعة. لا تظهر أرصدة. إن رُفض الصرف فالرسالة عامة.

## شؤون الطلبة

إدارة الملف الأكاديمي وتبويبات الأقساط والوصولات والمستندات. لا إصدار وصل إلا بصلاحية الصندوق.

## الطالب

من «حسابي» تظهر ذمته ووصولاته فقط.

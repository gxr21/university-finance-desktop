# دليل المسؤول

## الإقلاع

بعد `php bin/install.php` ادخل بـ `ADMIN_USERNAME` وكلمة `ADMIN_INITIAL_PASSWORD` ثم غيّرها فوراً. في الإنتاج استخدم سراً جديداً.

صلاحيات مدير النظام إدارية: مستخدمون، أدوار، هوية، هيكل أكاديمي، QR، نسخ احتياطي، تدقيق. الأرصدة والتقارير المالية تُمنح صراحة.

## اعتماد الحسابات

المستخدمون → الحالة `pending` → تفعيل → إسناد دور. تعطيل الحساب يلغي جلساته.

## الهوية

من «الهوية والإعدادات» تُحدَّث أسماء الجامعة والكلية والترويسة والختم. كل تغيير يُحفظ في `setting_revisions`.

## الأقساط والخصومات

أنشئ سياسة حسب السنة والنوع والمرحلة. عدد الأقساط 1 أو 2 أو 4 أو جدول مخصص. التطبيق: طلبة جدد فقط، أو الحاليون بلا وصولات. الخصم التاريخي لقطة ولا يتغير عند تعديل القاعدة.

## QR

إصدار رمز دخول عشوائي محدود العمر. يمكن إلغاؤه فوراً. لا يوسّع صلاحيات الحساب.

## النسخ الاحتياطي

زر النسخة يولّد SQL في `storage/backups/`. الاستعادة يدوية عبر MySQL.
